# web

Next.js (App Router) + TypeScript. Renders the explainer from `/public/data` JSON.

- Build it by pasting BLUEPRINT §6b into Claude Code (follow the build order — stop after
  stage 2 for the deployable vertical slice).
- Design tokens are in `app/globals.css` and `tailwind.config.ts` (BLUEPRINT §1.3).
- Never render a number that isn't in the JSON (BLUEPRINT §4 is the contract).

`npm install && npm run dev`
